# ЛР №3 по DevOps

**Вариант 36:** просмотр количества подтверждённых бронирований и выручки за выбранный период. Есть группировка по дням, неделям и месяцам.

Фронтенд сделан на HTML, CSS и JavaScript. Бэкенд взят готовый из [moscow-events](https://github.com/nelkor/moscow-events).

## Запуск

Нужен Docker. В папке проекта выполнить:

```bash
docker compose up -d
```

Открыть сайт: **http://localhost:8080**

## Как пользоваться

Выбрать даты начала и конца периода, группировку (дни / недели / месяцы) и нажать **«Показать отчёт»**. На странице будут графики, общая статистика и таблица. Результаты можно скачать в CSV.

## Что в Docker

- `db` — PostgreSQL с PostGIS, хранит данные.
- `backend` — готовый API преподавателя.
- `frontend` — NGINX, показывает сайт и перенаправляет запросы к API.

Все сервисы запускаются через `compose.yml`. Данные базы сохраняются в Docker volume.

Проверить контейнеры: `docker compose ps`.

Остановить проект: `docker compose down`.
